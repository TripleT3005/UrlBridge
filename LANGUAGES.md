# Languages

[English](#english) · [Deutsch](#deutsch)

## English

All translations were generated by Claude (AI). Files that a person has checked name the reviewer in the table and in the file itself. If you notice a mistake or know a better wording, please open an [issue](https://github.com/TripleT3005/UrlBridge/issues) or a pull request; reviewers are credited with their GitHub name if they agree.

The codes follow [BCP 47](https://www.rfc-editor.org/info/bcp47): ISO 639 language codes, ISO 3166 regions and ISO 15924 scripts. UrlBridge follows the Windows display language; missing texts fall back to the language named in `language.fallback`, otherwise to English.

This list is generated from the headers of the files in [`lang`](lang). After changing them, run `$env:UPDATE_LANGUAGES = 1; cargo test language_list` to update it; the CI fails if it is out of date.

## Deutsch

Alle Übersetzungen wurden von Claude (KI) erzeugt. Dateien, die eine Person geprüft hat, nennen die prüfende Person in der Tabelle und in der Datei selbst. Wenn dir ein Fehler auffällt oder du eine bessere Formulierung kennst, eröffne gern ein [Issue](https://github.com/TripleT3005/UrlBridge/issues) oder einen Pull Request; mit Einverständnis wird die prüfende Person mit ihrem GitHub-Namen genannt.

Die Codes folgen [BCP 47](https://www.rfc-editor.org/info/bcp47): ISO-639-Sprachcodes, ISO-3166-Regionen und ISO-15924-Schriften. UrlBridge folgt der Anzeigesprache von Windows; fehlende Texte fallen auf die in `language.fallback` genannte Sprache zurück, sonst auf Englisch.

Diese Liste wird aus den Köpfen der Dateien in [`lang`](lang) erzeugt. Nach Änderungen daran aktualisiert `$env:UPDATE_LANGUAGES = 1; cargo test language_list` sie; die CI schlägt fehl, wenn sie veraltet ist.
